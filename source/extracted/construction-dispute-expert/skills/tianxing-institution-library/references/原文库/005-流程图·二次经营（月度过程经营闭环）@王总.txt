# 二次经营管理办法 · 流程图（月度过程经营闭环）

> 性质：**按月循环**。每月从"一次经营交底 + 上月复盘"起步，月底回到"整理资料、归档 + 启动下月计划"。
> 左侧有一条"有问题"的回流线，直接回到"二次经营审核"节点。

## 一、启动段

| 序 | 环节 | 说明 |
|---|---|---|
| 1 | **一次经营交底 + 上月复盘** | 月度循环的起点 |
| 2 | 本月任务目标分解 | 把月度目标拆到人/事 |
| 3 | 针对本月目标开展**二次经营策划** | 产生 6 项策划 |
| 4 | **二次经营审核** | 审核节点；"有问题"则回流至本节点重做策划 |

## 二、六项策划（左半区，各有独立流程）

| 策划项 | 内容 | 后续动作 |
|---|---|---|
| 回款策划 | 准备资料 + 跟进流程 | 回款落实（跟踪到账情况） |
| 认价策划 | 确定内容 + 认价对象 | 认价确认（获取书面审批文件） |
| 签证事项策划 | 确定内容 + 准备证据 | 事项审核（**按时限提交业主/监理**） |
| 索赔价差策划 | 收集资料 + 测算金额 | 并入事项审核 |
| 设计变更策划 | 对接各方 + 推进审批 | 变更确认（获取书面审批文件） |
| 审批跟踪 | 每周更新进度台账 | 与上述各策划并行 |

> 上表 5 项策划中，签证、索赔价差两项汇入同一个"事项审核"节点；认价与变更各自"确认"。
> 最后统一进入 **审批跟踪（每周更新进度台账）**。

## 三、九项管理（右半区，各有对应的"管理办法"）

| 管理项 | 对应制度 | 输出 |
|---|---|---|
| 结算管理 | 结算管理办法 | 检查结果 |
| 对下招标管理 | 招标管理办法 | 检查结果 |
| 合同管理 | 合同管理办法 | 检查结果 |
| 材料管理 | 材料管理办法 | 检查结果 |
| 质量管理 | 质量管理办法 | 检查结果 |
| 安全管理 | 安全管理办法 | 检查结果 |
| 进度管理 | 进度管理办法 | 检查结果 |
| 现场文明施工管理 | 现场管理办法 | 检查结果 |
| （结算管理同时挂在左半区与右半区之间） | — | — |

## 四、收口与回流

| 序 | 环节 | 说明 |
|---|---|---|
| 5 | **月结算** | 汇总六项策划的执行结果 + 九项管理的检查结果 |
| 6 | **复盘**：分析原因 + 制定改进措施纳入下月重点 | 复盘结论回流到"下月"的启动段 → 形成闭环 |
| 7 | 整理资料、归档 + 启动下月计划 | 月度循环出口，也是下月入口 |

## 五、原图体现的关键管理逻辑

1. **二次经营 = 月度循环**，不是一次性动作；每个月的起点是"一次经营交底 + 上月复盘"。
2. **六项策划全部要求"取得书面文件/书面审批"**：回款落实到账、认价获取书面审批文件、签证按时限提交业主监理、变更获取书面审批文件——**书面化是二次经营的硬要求**。
3. **签证与索赔价差捆绑在同一"事项审核"**，说明二者在本公司口径里是同一条办事路径。
4. **审批跟踪要求"每周更新进度台账"**。
5. **九项管理制度与经营管理形成"制度—检查结果—月结算"的月度联动**：每项管理办法每月都要出"检查结果"，汇入月结算。
6. **月结算是枢纽**：向上承接策划执行，向下为复盘提供数据。
