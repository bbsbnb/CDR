# 工程纠纷核验工具包

工程纠纷处理的可复用模板集。所有模板按"能直接填、能直接贴进会议材料"设计，不含空话。

使用规则：先扫八阶段清单定位风险段，再对每条争点跑四要素核验表，然后做责任划分与金额测算，最后用七段式加一附骨架输出（含起因三层拆解、公司处理意见与依据清单）并附期限倒排表。

---

## 模板一：八阶段快速风险扫描清单

逐段过，不跳段。命中即记录，不命中也写"未发现"。

| # | 阶段 | 扫描动作 | 命中 |
|---|------|---------|------|
| 1 | 招投标 | 招标文件 / 投标文件 / 中标通知书 / 备案合同四者实质性内容是否一致 | |
| 2 | 合同签订 | 是否存在两份及以上版本；签约日期是否倒挂；质保金与缺陷责任期约定是否冲突 | |
| 3 | 开工准备 | 开工令 / 开工报告 / 进场记录是否齐全且日期一致；施工许可是否在开工前取得 | |
| 4 | 施工过程 | 变更是否有书面签证；签认人是否具备授权；清单漏项是否已认价 | |
| 5 | 工期 | 延误事件是否在合同约定期限内提出过书面主张；停工 / 复工是否有函件 | |
| 6 | 材料与价格 | 认价单是否签署；调差基准与风险幅度是否明确；甲供材扣款是否有对账 | |
| 7 | 竣工验收 | 竣工日期依据是哪份文件；甩项与整改是否闭环；是否未验收即使用 | |
| 8 | 结算与质保 | 送审是否有签收凭证；审减理由是否书面；质保金返还条件是否成就 | |
| 附 | 分包与劳务 | 分包主体资质是否匹配；资金流是否异常；工资是否由总包代付 | |

## 模板二：证据链四要素核验表

每条主张都要四项齐。缺项即为风险点，必须给出补救方案。

| 主张 | ①合同依据 | ②事实发生 | ③数量金额 | ④签认手续 | 缺口 | 补救方案 |
|------|----------|----------|----------|----------|------|---------|
| （如：增加工程量 320 m³） | 专用条款第 X 条 / 变更程序约定 | 2026-05-12 监理指令编号 XXX | 计量单第 X 期 320 m³，单价 XX 元 | 监理签认、项目经理签字（有授权？） | ④签认人无授权文件 | 调取授权书；补监理确认函；以计量支付记录补强 |

**核查要点：**
- 合同依据要落到"具体条款号 + 程序要求"，不能只写"合同有约定"。
- 事实发生要能对应到时间点，含发生、通知、确认三个时点。
- 数量金额要写清口径：工程量来源（图纸 / 计量 / 实测）、单价来源（清单 / 认价 / 定额）。
- 签认手续要核到人：签字人是否有授权、签认时间是否在事件发生之后且合理期间内。

## 模板三：责任划分表

| 责任主体 | 责任内容 | 责任比例 / 区间 | 依据类型 | 备注 |
|---------|---------|---------------|---------|------|
| 发包人 | 图纸交付延迟 22 天 | 主要责任 | 【合同约定】 | 有移交记录 |
| 监理 | 未及时发布指令 | 次要责任 | 【合同约定】 | 指令缺失 |
| 总包 | 未在期限内报送顺延 | 自身程序瑕疵 | 【合同约定】 | 影响索赔成立 |
| 分包 | 人员投入不足 | 部分责任 | 【经验判断】 | 需考勤佐证 |

依据类型统一用四档标注：`【合同约定】` `【法律规定】` `【行业惯例】` `【经验判断】`。

## 模板四：期限倒排表

所有期限写成绝对日期，不接受"尽快""及时"。

| 事项 | 起算点 | 期限 / 期限依据 | 到期日 | 剩余天数 | 动作 | 状态 |
|------|-------|---------------|-------|---------|------|------|
| 索赔意向通知 | 知道或应当知道索赔事件之日 | 合同专用条款约定（常见 28 天） | YYYY-MM-DD | | 发函并留送达凭证 | 未启动 / 办理中 / 已完成 |
| 工期顺延申请 | 延误事件发生之日 | 合同专用条款约定 | YYYY-MM-DD | | 报监理与发包人 | |
| 诉讼时效 | 权利受损或应付之日起 | 《民法典》诉讼时效规定 | YYYY-MM-DD | | 发催告函中断时效 | |
| 工程价款优先受偿权行使 | 发包人应当给付工程价款之日 | 现行司法解释规定期限 | YYYY-MM-DD | | 评估是否主张 | |
| 举证期限 | 仲裁 / 诉讼受理后法院或仲裁庭指定 | 程序通知 | YYYY-MM-DD | | 组织证据册 | |

> 具体期限天数与起算规则**以现行有效法律法规及本项目合同专用条款为准**，本表仅作结构模板；进入正式程序前须经执业律师核验。

## 输出红线

1. 缺资料写"资料缺口"，不臆造事实。
2. 金额必须公开口径与假设，不给单一确定数字。
3. 经验判断必须标注，不与合同约定、法律规定、公司制度混同表述。
4. **引用公司制度必须带编号与版本状态**（`【公司制度（讨论稿）07 号】`）；不得把讨论稿/拟定稿说成已生效制度；**内部制度不对抗外部相对人**。
5. **起因分析不得停在"某人责任心不强"**——必须拆到作业层、制度执行层、制度本身层，并落到可执行的改进动作。
6. **第六节「公司处理意见」是对内汇报材料，不得当作对外交涉口径直接发给对方**；对外表述须另行改写。
7. 不承诺结果，不出具正式法律意见书；正式文书与程序动作提示"须经执业律师复核"。
8. 涉刑线索单独提示移交，不作实体判断。
9. 全部输出中文，法条用《》标注全称并注明以现行有效版本为准。
